# JavaScript DOM Manipulation

Holberton School browser exercises demonstrating DOM selection, event handling,
class changes, element creation, and Fetch API requests.

## Tasks

- 0: Change the header text color.
- 1: Change header color after a click.
- 2: Add the `red` class after a click.
- 3: Toggle between `red` and `green` classes.
- 4: Append a list item after a click.
- 5: Update header text after a click.
- 6: Fetch and display the fifth Star Wars character's name.
- 7: Fetch and list Star Wars film titles.
- 8: Fetch a French greeting, including when the script loads in the head.

## Testing

Include the relevant `N-script.js` in the provided task's HTML test page.
The pages must be opened in a browser with network access for the Fetch tasks.
