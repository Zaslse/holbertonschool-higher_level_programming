# JavaScript Warm-up

Holberton School introduction to JavaScript scripting with Node.js 14.

## Tasks

- 0: Define a constant and print it.
- 1: Print three programming-language messages.
- 2: Respond to the number of command-line arguments.
- 3: Print the first command-line argument.
- 4: Concatenate two arguments into a sentence.
- 5: Convert an argument to an integer.
- 6: Print an array of strings with a loop.
- 7: Repeat a message using a loop.
- 8: Print a square of X characters.
- 9: Add two command-line integers with a function.
- 10: Compute a factorial recursively.
- 11: Find the second largest argument.
- 12: Update an object property.
- 13: Export an addition function from a module.

## Usage

Run a task using `node 0-javascript_is_amazing.js`, or execute the file directly
on Linux after setting its executable permission. All scripts use the
`#!/usr/bin/node` shebang and semistandard JavaScript style.
